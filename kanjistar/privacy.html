プライバシーポリシー

漢字スター（Kanji Star）／ 最終更新日：2026年10月8日

本ポリシーは、白梅デジタル（以下「当方」）が提供するiOSアプリケーション「漢字スター」（以下「本アプリ」）における、利用者情報の取扱いについて定めるものです。

1. 収集する情報

当方は、本アプリの提供にあたり、以下の情報を取得する場合があります。

Appleでサインイン利用者が任意でサインインした場合に限り、Appleから提供される識別子、メールアドレス、氏名を取得します。氏名とメールアドレスは初回サインイン時のみ提供されます。利用者はAppleの機能により、メールアドレスを非公開（プライベートリレー）にすることができます。
学習の進行状況クリアしたステージ、所持アイテム、設定などのゲームデータ。
購入情報App内課金の購入状態。決済はすべてAppleが処理し、当方がクレジットカード番号等の決済情報を取得することはありません。

2. 情報の保存場所

本アプリは、利用者情報を当方のサーバーに送信しません。情報は次の場所にのみ保存されます。

  • 端末内：ゲームデータおよび設定。
  • 利用者のiCloud：機種変更時にデータを引き継ぐため、利用者本人のiCloudアカウントにゲームデータを保存します。当方はこのデータを参照できません。

3. 利用目的

  • 学習の進行状況を保存し、次回起動時に復元するため
  • 端末を変更した際にデータを引き継ぐため
  • 購入されたコンテンツを提供し、サブスクリプションの状態を確認するため

4. 第三者への提供

当方は、利用者情報を第三者に販売、譲渡、貸与しません。法令に基づく開示請求があった場合を除き、第三者に提供することはありません。

5. 広告・解析ツール

本アプリは、第三者の広告ネットワークおよびアクセス解析ツールを使用していません。端末の広告識別子（IDFA）を取得しません。

6. 児童のプライバシー

本アプリは日本語学習を目的としており、児童が利用する可能性があります。当方は、児童から個人情報を意図的に収集することはありません。保護者の方で、お子様の情報が送信されたとお考えの場合は、下記までご連絡ください。速やかに削除いたします。

7. データの削除

利用者は、いつでも以下の方法でデータを削除できます。

  • 本アプリを端末から削除すると、端末内のデータは削除されます。
  • iCloud内のデータは、iOSの「設定 → Apple ID → iCloud → アカウントのストレージを管理」から削除できます。
  • Appleでサインインの連携は、「設定 → Apple ID → サインインとセキュリティ → Appleでサインイン」から解除できます。

8. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。重要な変更を行う場合は、本アプリ内または本ページにてお知らせします。
